# isoziyuan-tools (爱搜资源 - Cloudflare 全能免费建站工具箱)

基于 Cloudflare 免费服务打造的全自动化建站工具箱，支持一键搭建各类轻量高效的个人云端服务。

## 🚀 已支持功能
1. **个人导航站**
   - 架构：Cloudflare Pages + D1 数据库
   - 特色：免服务器、响应式自适应布局、自带后台管理、支持分类/图标/密码认证
2. **免费云网盘**
   - 架构：Cloudflare Pages + D1 数据库 + R2 存储桶
   - 特色：10GB 免费空间、0 出站流量费、支持提取码、文件夹管理、文件直链下载与访问控制
3. **个人轻量博客 (纯净版 - 无需 R2)**
   - 架构：Cloudflare Pages + D1 数据库
   - 特色：针对未开通 R2 存储的用户设计，零门槛秒级搭建，自带 /admin 后台，在线撰写 Markdown 文章
4. **个人全能博客 (图床版 - 带 R2)**
   - 架构：Cloudflare Pages + D1 数据库 + R2 存储桶
   - 特色：在轻量版基础上集成 R2 对象存储图床，后台写文章时支持一键上传图片并自动插入 Markdown 正文
5. **账号与资源管理**
   - 支持一键识别/清除授权
   - 支持一键扫描与删除所有关联的远程资源

## 🛠️ 快速开始
双击运行 `一键部署工具箱.bat`，按照控制台菜单提示选择对应编号即可。
全部流程自动检测环境、调起浏览器授权并完成云端建库建桶与部署。
